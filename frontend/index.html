About The Platform

What is Lung CT Imaging?

Lung Computed Tomography (CT) generates high-resolution transverse slice imagery of the thorax, mapping tissue density variations to identify tumors, infections, and interstitial lung diseases.

Why Noise Matters?

Electronic systems add Gaussian noise, while photon starvation causes Poisson shot noise. These artifacts degrade signal quality, mask fine anatomical anomalies, and compromise automated clinical diagnostic accuracy.

AI Denoising Solution

Our solution utilizes a customized U-Net++ architecture to perform pixel-level segmentation, detecting noise regions, classifying them by source, and generating quantitative severity estimations.

4-Model Deep Learning Architecture

Four specialized deep neural network models engineered to detect, classify, and quantify distinct physical CT noise modalities.

MODEL 1

U-Net++ (Nested UNet)

Gaussian & Poisson Noise Segmentation

Utilizes dense nested skip pathways connecting encoder and decoder sub-networks to capture both high-frequency electronic thermal noise and low-dose quantum photon starvation artifacts.

Target Artifacts: Gaussian + Poisson
Backbone: ResNet18 / Nested Conv
Input Resolution: 512 × 512 × 1 ([-1, 1])
Output Format: 3-Class Pixel Mask
Dice Accuracy: 98.86%
Dense Skip Connections Deep Supervision Bounding Box HUD
MODEL 2

Attention U-Net

Poisson & Speckle Noise Segmentation

Integrates Additive Attention Gates (AG) that learn to suppress irrelevant background lung parenchyma while selectively focusing gradient activation on subtle multiplicative speckle scatter.

Target Artifacts: Poisson + Speckle
Backbone: Attention Gated UNet
Input Resolution: 512 × 512 × 1 ([0, 1])
Output Format: 4-Ch Attention Mask
Checkpoint: Joshna.pth (125MB)
Attention Gates Co-occurrence Logic Red/Green Overlay
MODEL 3

DeepLabV3+

Salt & Pepper + RVIN Noise Segmentation

Employs Atrous Spatial Pyramid Pooling (ASPP) with dilated convolutions to capture multi-scale contextual features, accurately isolating isolated impulse outliers from fine anatomical tissue textures.

Target Artifacts: Salt-Pepper & RVIN
Backbone: ASPP + Decoder Module
Input Resolution: 512 × 512 × 1 ([0, 1])
Output Format: 3-Class Pixel Mask
Checkpoint: Jahnavi.pth (276MB)
Dilated Convolutions Impulse Detection Amber/Purple Map
MODEL 4

NoiseCNN

Quantization & Periodic Noise Classification

Deep feature extractor paired with 2D Fast Fourier Transform (FFT) magnitude analysis for fast whole-scan screening of ADC bit-depth truncation and harmonic periodic stripe artifacts.

Target Artifacts: Quantization + Periodic
Backbone: Deep CNN + Global Pool
Input Resolution: 128 × 128 × 1 (Min-Max)
Output Format: Class Confidence Dist.
Checkpoint: Vasanth.pth (2.4MB)
2D FFT Spectrum Softmax Probability Harmonic Detection
